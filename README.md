📘 Грубо говоря электронный дневник

Грубо говоря электронный дневник — это десктопное WPF-приложение на C#, предназначенное для ведения электронного дневника: управление студентами, предметами, оценками и отображение их в удобном интерфейсе.

🧰 Технологии проекта

Проект использует:

C# (.NET Framework)

WPF (XAML) — пользовательский интерфейс

Entity Framework 6 (EDMX) — работа с базой данных

SQL Server / LocalDB — хранилище данных

MVVM-подход (частично) — разделение логики и UI

App.config — настройки подключения

🚀 Как запустить проект

Установить Visual Studio 2022 или новее.

Открыть файл решения:
RoughlyElectronicDiary.slnx

Убедиться, что установлен пакет:

EntityFramework 6.x

Проверить подключение к базе в App.config (строка <connectionStrings>).

Запустить проект (F5).

🗄️ База данных

Проект использует Entity Framework Database-First, а файл Model1.edmx содержит структуру таблиц:

Students

Subjects

Marks

При первом запуске EF создаёт и инициализирует БД автоматически, если включена поддержка LocalDB.
